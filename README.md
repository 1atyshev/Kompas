# MUST — Telegram habit tracker + Google Sheets (prototype)

Проект: Telegram-бот для трекинга привычек/метрик и ежедневной “миссии дня”, с геймификацией (XP/уровни/стрики) и интеграцией с Google Sheets. В перспективе — “ИИ‑коуч” с дневником и еженедельной аналитикой заметок.

В репозитории намеренно собрана “памятка для следующей модели/разработчика”: что работает сейчас, где что лежит, как деплоится, какие переменные нужны.

Важно: **секреты (пароли, токены, ключи) не храним в репозитории**. Этот README описывает *что нужно* и *где это на тестовом сервере*, но сами значения передаются отдельно.

## Что есть сейчас (функции)
### Telegram UX
- Экран “🏠 Сегодня”: миссия дня + кнопки трекеров + быстрые действия.
- “✅ Трекеры”: список, создание, редактирование.
- “🗒 Дневник”: заметка дня (текст/голос), несколько сообщений, автозакрытие, история и недельные отчеты.
- “⚙️ Настройки”: утро/вечер (напоминания), Google Sheets, часовой пояс.
- Онбординг: при `/start` бот просит текущее локальное время (HH:MM) и сохраняет часовой пояс (UTC±X), чтобы корректно считать даты и напоминания.

### Трекеры
- Типы: `binary`, `time`, `count`, `scale (1–10)`.
- Логи: запись значений/отметок, частичное выполнение для бинарных.
- Цели (week/month/year) и режимы отображения прогресса на кнопках.
- Стрики трекеров: режимы `activity`/`goal`, периоды, min_value, partial_ok.
- XP и уровни: начисление XP при действиях.

### XP‑правила (кастомизация)
- `time`: XP за 1 час (в итоге XP = `value * xp_per_hour`).
- `count`: XP‑карта значений, например `1-5 2-10 3-30` (за значения вне карты XP=0).
- `scale (1–10)`: задаётся XP за 1 и за 10, XP за 2–9 считается линейно (интерполяция).

### Google Sheets
- OAuth подключение Google (кнопка в настройках).
- Создание таблицы из шаблона, заливка `raw_*` листов.
- Заполнение сетки `Habits Tracker 2026`:
  - имена трекеров;
  - валидации (без dropdown‑стрелок);
  - перенос логов в сетку;
  - восстановление формул `TOTAL`/`Progress` и заполнение колонок streak/goal (в текущей реализации).
- Удаление листа `Setup` (если присутствует).

### Синхронизация бот → Google Sheets
- Бот хранит всё в БД.
- После каждого действия в боте запускается дебаунс‑синк (~2 секунды): обновляются `raw_*` и грид в таблице.

## Что планируется (roadmap)
- Ежедневный дневник (расширение): голос → транскрипт, теги/настроение, “итог дня”.
- ИИ‑коуч:
  - еженедельная аналитика дневника (темы/паттерны/что помогает/что мешает/эксперименты);
  - чат по итогам недели с сохранением истории;
  - рекомендации по привычкам и целям.
- Более чистая архитектура (слои, миграции, воркеры), см. `ARCHITECTURE.md`.

## Быстрый старт (локально)
```bash

source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # если заведём шаблон; сейчас .env создаётся вручную

```

## Запуск в Docker (как на сервере)
```bash
docker build -t habitbot .
docker run -d --name habitbot --env-file .env -p 8080:8080 habitbot
docker logs -f habitbot
```

## Переменные окружения
Минимум:
- `BOT_TOKEN` — Telegram bot token.
- `DATABASE_URL` — строка подключения SQLAlchemy (Postgres в проде / SQLite локально).

Google OAuth + Sheets:
- `GOOGLE_OAUTH_CLIENT_ID`
- `GOOGLE_OAUTH_CLIENT_SECRET`
- `GOOGLE_OAUTH_REDIRECT_URI` (например `https://<domain>/oauth2/google/callback`)
- `GOOGLE_OAUTH_PORT` (обычно `8080`)

ИИ (chat + транскрипция):
- `OPENAI_API_KEY` — нужен для транскрипции голосовых (Whisper).
- `DEEPSEEK_API_KEY` — ключ DeepSeek (если используем для чата).
- `AI_PROVIDER` — `openai` (по умолчанию) или `deepseek`.
- `OPENAI_CHAT_MODEL` (например `gpt-4o-mini`)
- `DEEPSEEK_CHAT_MODEL` (например `deepseek-chat`)
- `OPENAI_AUDIO_MODEL` (например `whisper-1`)

Service account (если используется для Drive/Sheets операций):
- `GOOGLE_SA_JSON` — путь к json‑ключу внутри контейнера (например `/app/sa.json`)
- `GOOGLE_DRIVE_PARENT_ID` — папка в Google Drive (опционально)

Важно: реальные значения не коммитим. На сервере они лежат в `/root/habitbot/.env`.

## Где что лежит в репо
- `bot.py` — весь Telegram‑бот (aiogram), состояния FSM, XP, стрики, онбординг, напоминания.
- `models.py` — SQLAlchemy модели.
- `db.py` — создание engine + `db_session()`.
- `google_sheets.py` — интеграция с Google Sheets (создание/заливка/синк грида).
- `scripts/google_sheets_script.gs` — Apps Script (вспомогательный, не обязателен для работы бота).
- `habitbot_template_EN.xlsx` — шаблон таблицы Google.
- `ARCHITECTURE.md` — целевая архитектура/слои/план миграции.
- `DATABASE_SCHEMA.md` — расширенная целевая схема БД.

## Архитектура (кратко)
Текущее состояние:
- один процесс (`bot.py`) + SQLAlchemy;
- Postgres в Docker (на сервере) или SQLite локально;
- напоминания (утро/вечер) — цикл внутри процесса, с учетом `User.tz`.

Интеграции:
- Google OAuth callback принимает встроенный aiohttp сервер в `bot.py` (порт `GOOGLE_OAUTH_PORT`).
- Google Sheets: бот пишет “сырьё” в `raw_*` листы и отображение в `Habits Tracker 2026`.
